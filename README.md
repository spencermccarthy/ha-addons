# McCarthy House Add-ons

Home Assistant add-on repository. Add this URL under
**Settings → Add-ons → Add-on Store → ⋮ → Repositories**:

```
https://github.com/spencermccarthy/ha-addons
```

## Add-ons

- **eBUS Capture** (`ebus_capture`) — durable capture of undecoded eBUS
  telegrams from the C6 + a compact HA sensor context, with a read-only JSON API
  for the `ebus` skill's `keys` / `history` / `correlate` commands.
